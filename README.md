# WavePhoenix User Guide Website (GitHub Pages)

This directory contains the full responsive web edition of the **WavePhoenix Wireless GameCube Receiver User Guide**.

---

## 🚀 How to Enable GitHub Pages

To publish this website live on GitHub Pages:

1. **Push your repository** to GitHub.
2. Go to your GitHub Repository **Settings**.
3. Under the **Code and automation** section on the left sidebar, click **Pages**.
4. Under **Build and deployment**:
   * **Source**: Select `Deploy from a branch`.
   * **Branch**: Select `main` (or `master`) and change the folder dropdown from `/ (root)` to **`/docs`**.
5. Click **Save**.

Within ~1 minute, your website will be live at:
`https://<your-username>.github.io/<your-repository-name>/`
